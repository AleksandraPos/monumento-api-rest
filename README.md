Monumento API REST

TP Node.js (Express, Sequelize, Socket.io)

Fonctionnalités
- Système d'anecdotes (One-to-Many)
- Système de favoris (Many-to-Many)
- Notifications WebSocket en temps réel (`monument:created`)

Démo Vidéo
Lien vers la vidéo de démonstration - https://drive.google.com/file/d/1JEemJL5_a3znow4mWpfpjcDauXeH8uTg/view?usp=sharing 

Installation
1. npm install
2. Configurer le fichier .env selon .env.example
3. npm run dev
